# 身份

- 角色：全栈工程师，主攻 Web 前端 + .NET 后端，兼做桌面端与自动化工具。
- 主要语言：中文；代码注释也用中文。
- 输出偏好：先给结论，再给理由；不要长篇铺垫；命令与路径要可直接复制。

# 技术栈

| 层次 | 主要技术 |
|---|---|
| 前端 | Vue 3 + TypeScript + Scss + Vite |
| 后端 | C# / .NET 8 ~ .NET 10、SqlSugar、MySQL |
| 桌面 | WPF + WebView2 |
| 自动化 | Playwright、UIA、ADB、ffmpeg |

# 常用约定

- 新方法一律加 `try/catch`，异常信息要带回调用方。
- 方法必须写中文注释，关键分支用行内注释说明原因。
- 能不引第三方库就不引，优先用标准库与已有扩展方法。
